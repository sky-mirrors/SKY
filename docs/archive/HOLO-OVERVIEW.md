# Holo（HoloStarmap）产品与架构总览

> 快照日期：2026-09-21。本文是面向讲述的"一页纸"总览：产品定位 → 用户所见 → 请求全链路 → 质量闭环 → 双视角话术 → 现状诚实账。
> 深度细节见同目录：ARCHITECTURE.md（静态架构）、REQUEST-LIFECYCLE.md（机制旅程）、EXAM-RUNBOOK.md（考试手册）、LIFECYCLE-GAPS.md（缺陷注册表）。

## 0. 一句话定位

Holo 是一个**本地优先的桌面 AI 工具操作系统**：它不把 AI 当聊天窗口交付，而是当**一颗颗可点击、可组装、可撤销的"工具星"**交付（产品哲学：RaaP，Robot-as-a-Product）。125 个节点组成 3D 星图，四层结构：**L0 用户恒星（1）→ L1 行星（6 颗基础能力）→ L2 卫星（岗位工具）→ L3 社区星尘（98 个，带热度衰减）**。

技术形态：Vue 3 + Pinia（17 个 store）+ Three.js + Electron（多窗口），数据落 SQLite Vault + safeStorage 加密，模型可插 8 家预设（DeepSeek / OpenAI / Anthropic / 通义 / 智谱 / Moonshot / 零一万物 / Ollama 本地）。

## 1. 用户视角：从开机到拿结果

### 1.1 首次启动

**OnboardingWizard 五步向导**：🌌 欢迎 → 👤 选角色（人力/财务/销售/法务/通用，决定星图初始模板）→ 🧠 连接 AI 大脑（API 地址/密钥/模型，连不上可跳过，星图显示"灰暗降级"态）→ 📖 术语偏好（专业模式"知识检索、模型调用" vs 轻松模式"知识查询、AI对话"）→ 🚀 就绪清单。星图首启三幕动画：L0 脉冲 → 五色星尘点击选角 → 星尘爆散生成个性化星图。

### 1.2 两种主模式（标题栏 🌌/🛠 切换）

**工作台模式**（四栏）：

- **左 WorkbenchNav**：会话切换、工具窗口入口（🧩 管线编辑器、🔍 调试中心、📊 压测台、⚖️ 规则审核，各开独立 Electron 窗口）。
- **中 DialogPanel**（对话主面板）：
  - 三个模式页签：**指令 / Plan / Teach**——指令=直接执行；Plan=先出执行计划等确认；Teach=教学式沉淀。
  - 消息支持 Markdown、文件附件卡片（点击直接用系统程序打开）。
  - 每条长结果带**操作条**：📊 预览编辑 / 📄 导出为 Word / 🌐 导出为 HTML / 📋 复制 / 👍 有用 / 👎 无用 / ↩️ **撤销执行**（把本次执行创建/修改的文件移入 `Desktop\holo-trash` 回收站）。
  - 输入区多种**确认条**：⏳ 计划确认、🟡 意图确认（"Agent翻译结果：意图+参数"）、🔴 **槽位填充**（列出宏的必填参数逐个填空）、事实冲突裁决、风险确认。
  - 附件上传可选目标：**会话 / 流水线 / 知识库**（约 30 种文本格式白名单）。
  - **从星图拖节点进对话框** = 自动编排（"已将 N 个工具加入编排: A + B"）。
- **右 RuntimePanel**（五区）：路由与执行状态（等待确认/候选选择）、热插拔内核与 Pack 状态、**验收考试卡**、Token 预算（会话/日/月三档 + 熔断器）、探针流。
- **底 StatusBar**：内核状态、Pack 数、漏斗指标、DAG 进度、探针计数、熔断按钮。

**星图模式**（3D 主舞台）：

- 悬停 500ms 显示连接线与牵引光束；**Ctrl+左键多选** → 加入编排/流水线。
- **双击 L2 星 = 直接执行该技能**（promptTemplate 填空）。
- **把 L2 拖到 L1 上 = 升降级**。
- L3 社区星生命周期：热度衰减 → 7 天内可锚定 → 坍塌后可复活。
- **NodeDetailPanel**：锁定状态、社区热度、**L0 优先级滑杆**、组合工具链、输出 Schema；按钮"加入编排 / 加入流水线 / 锁定到我的配置"。

### 1.3 L0 用户本体弹窗（五页签）——个人能力管理中枢

1. **已安装技能**：卡片管理 + 导出 + 导入 `.skill.json`。
2. **技能商店**：21 个技能包（深度网络研究、知识库问答、Playwright 测试、GitHub 审查、Slack/Gmail/Notion/Obsidian 集成…），一键"安装技能+MCP"。
3. **MCP 工具商店**：5 个官方 MCP（Filesystem / Memory / Sequential Thinking / GitHub / Context7）。
4. **MCP 连接管理**：状态灯、每工具**权限三级（只读/读写/执行）** + 自动允许勾选 + 白名单模式 + 调试日志。
5. **权限与沙箱**："🔒 本地沙箱已启用——所有 PDF/Excel 文件仅在本地解析，不上传任何云端" + 操作审计日志（可导出 CSV）。

### 1.4 L2 技能清单（24 个 manifest，覆盖五角色）

- **财务**：财报一句话解读、报销合规检查、周报草稿、Excel 摘要、预算预测、KPI 报告
- **法务**：合同风险审查、条款对比、ND 审查清单
- **HR**：简历初筛、入职引导、考勤异常说明、离职交接、公告草稿、政策文档问答
- **销售**：销售提案、客户邮件、竞品分析
- **通用**：会议纪要、文档翻译、PPT 大纲、邮件分类、文件解读助手、文件创建器
- 另支持自定义宏：对话框保存（名称/关键词/步骤）、导出 `.blueprint.json` 分享、导入即用。

### 1.5 可观测与质量工具

- **调试探针**：每步执行留痕（来源、模型档位、temp/maxTokens、Tokens 与 ¥成本、输入输出快照、错误堆栈）；独立调试窗口含**时间旅行滑杆**与**性能剖析瀑布图**；支持 ❄️ 冻结、📦 导出调试包、🔄 重放探针。
- **Token 压测台**：对比实验，输出"调用次数 / Token / 费用 / 延迟 / 各类缓存命中 + 节省%"对比表。
- **规则审核面板**：领域规则（finance/legal/hr）生命周期管理——五态流转、误报率图表、来源引用、人工裁决表单。
- **验收考试**：见第 3 节。

## 2. 一次请求的完整走线

以"帮我把这份合同的风险条款标出来"（文件拖入对话框）为例：

### 第一段：入口（dialogStore.sendMessage）

1. 生成 `activeTraceId`（全链路归因 ID）+ 捕获 `originSessionId`（**会话归属**——中途切会话，回复仍写回发起会话）。
2. 会话绑定知识库时：`searchKnowledge(内容, top5)`，命中片段以 `【知识库检索结果…】` 前缀拼入 prompt，同时点亮"知识库投喂员"星。
3. 进入**六层拦截漏斗** L0→L0.5→L1→L2 RaaP→L3→L4，逐层尝试"不花 token"地解决：
   - **L0 规则/命令**：正则命中直接执行，零 token；
   - **L0.5 轻量翻译**：短输入的廉价意图归一；
   - **L1 单工具直投**；
   - **L2 RaaP 检索**：向量+关键词双路检索 manifest，匹配分受**反馈权重调制**（👍 过的技能 +mod×0.5）；缺参 → 🔴 槽位填充暂停点；置信度不足 → 🟡 意图确认或候选列表；
   - **L3/L4 通用 LLM 路径**：Plan 模式出计划等确认；竞争模式下多 Pack 竞标。
4. **负反馈正则护栏**：上一条回复含"不对/找不到/搞错了"时，L2 直接跳过——纠正性反馈不进工具匹配。

### 第二段：宏执行（macroExecutor）

5. L2 manifest 展开：`paramMapping` 把文件路径绑进 DAG 步骤；**执行指纹缓存**命中则整步复用零 token；并行分组跑无依赖步骤；`dagCheckpoint` 断点续跑。
6. 步骤为四类工具：`knowledge_search / read_file / llm_generate / shell_exec`；文件读取走 Electron IPC（jschardet 转码、512KB 上限、路径校验）。
7. **FactGuard** 事实护栏：关键数值被改动时拦截（critical 中断 / semi 提示确认）；写文件登记 SideEffectManifest 供 ↩️ 撤销。
8. 档位降级链 pro→standard→mini→nano→规则；**tier 只改 maxTokens/temperature 上限，从不切换模型**（确定性承诺）。

### 第三段：模型网关（apiStore.chatCompletion，九道关）

9. ① 就绪/熔断检查 → 失败走 **M20 透明降级链**（云端 → 本地 Ollama，UI 无感）→ ② **偏好注入**（记忆面板设置项变成 `[用户偏好]` system 前缀；考试/压测流量跳过）→ ③ **语义缓存**（命中零 token 返回）→ ④ **smartRoute** 选档（nano 512tok/0.1 → pro 8192tok/0.7）→ ⑤ **预算闸** → ⑥ 三种出口：Electron IPC 转发（主进程 safeFetch，SSRF 防护 + IP pinning）/ Ollama 渲染进程直连 / Anthropic 分支 → ⑦ 超时阶梯（60/150/240/300s，设置可调 0.5x–5x）→ ⑧ SSE 流式回传 → ⑨ **成本记账**：真实 usage 按 tier 价格表计价（本地记 ¥0），cacheHitTokens 真实入账，`debug:record-cost` 带 traceId 落调试器。
10. 结果经**结果美化师** beautify 成 Markdown 交付 → 操作条出现 → 👍/👎 进入学习回路。

### 第四段：三条学习回路

- **手动偏好**：记忆面板"偏好设置" → 全量注入每次请求（实证：设"简洁"后周报从 670 token 冗长变 106 token 干净）。
- **反馈权重**：👍+0.10 / 👎−0.15 / 撤销−0.20，钳位 ±0.50，每 24h 衰减，直接改下次技能检索排序；竞争模式下负反馈把胜出 Pack 的质量 EMA 拉到 0.2。
- **ZOL 零 token 学习**：路由器统计 success / failure / **overkill** 三态，每 20 次自动调档位阈值——全自动、零 token、本地持久化。

## 3. 质量闭环：18 题验收考试

Holo 给自己安排了一套**高考**：18 道真实办公题（文档 5 / 数据 4 / 信息 4 / 文件 5），素材在桌面 `HoloExam` 目录。考试特点：

- **走真实主路径**：考题穿过与真人使用完全相同的六层漏斗、FactGuard、暂停点（禁止另写 benchmark 平行实现）。
- **判卷结合制**：硬断言（数值±容差 / 关键信息 / 文件存在 / 目录模式，起子进程真查文件）+ 版本化模型判卷（只输出 `{"deliverable": true/false}`）。
- **流量隔离**：`examRegistry` 注册表识别考试流量——**学习回路隔离**（不污染偏好与缓存阈值）但**记账照常**（按 traceId 归因 token 花费）。
- **及格线先定死**：可交付率 80% / 零干预率 60% / 平均耗时 2 分钟；成绩单导出 `exam-report.json`；每轮抽 20% 人工复核。

**诚实账**：首考（09-20）可交付率 5.6%（暴露 8 题误路由、7 题超时）；修完 A3 批后复考（09-21）**44.4%，零干预 72.2% ✓**，误路由与超时归零。结论仍 **NO-GO**（<80%），瓶颈已从"系统坏了"迁移到"本地 3b 模型太弱"（文件操作拒答 3、答非所问 2、算错 2、执行偏差 2）。

## 4. 双视角讲述话术

**给普通用户（30 秒版）**：
"Holo 是一张你的 AI 工具星图。把文件丢进去或双击一颗星，它自动找到对应技能、组装流水线、把结果整理好给你——合同审查、周报、会议纪要、报销核对都会。不满意点 👎 或一键撤销重来，点 👍 它下次更懂你。你可以让它用本地模型，**文件永不上云**。它还给自己安排了 18 题办公考试，每答一题都有成绩单——不吹牛，考多少分说多少分。"

**给开发者（架构叙事版）**：
"这是一个把'调 LLM'工程化的实验：**微内核 + 事件总线 + 六层拦截漏斗**（每层先试图不花 token 解决），**tier 确定性**（档位只调参数、从不换模型），**fail-closed 安全门**（双引擎审计、FactGuard、MCP 三级权限、SSRF 防护、路径校验、shell 白名单），**本地优先**（SQLite Vault + safeStorage、密钥加密、离线降级）。可观测性是一等公民：每步探针带 traceId、时间旅行回放、真实成本记账到分。最独特的是**诚实工程文化**：213 项代码审计 + 对账报告揪出'声称已修'的水分；LIFECYCLE-GAPS 缺陷注册表（G/H/F/EXAM 四族）持续记账；走真实主路径的验收考试，及格线先定死再开考，事故也入册。当前 89 个测试文件 1706 用例全绿，验收 44.4% NO-GO——但它知道自己差在哪。"
