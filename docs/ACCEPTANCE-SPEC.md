# 验收考试规格 v1.0

> 目的：回答"Holo 能不能解决用户的问题"。成绩单的单位不是 Holo 的指标，是**用户的问题被解决的比例**。
> 及格线定死日期：2026-09-19（先定线后开考，修订需新版本号并注明理由）。
> 状态：规格参数已确认；活儿集待用户补充（5~10 题）。

## 命题

### 固定回归集（18 题，版本可比，目标用户语言）

| 类 | 题数 | 题目要点 |
|---|---|---|
| 文档 | 5 | 会议记录→正式纪要（附原始记录）；周报（附要点）；文件转 PDF；商务邮件改写；文档→一页摘要 |
| 数据 | 4 | 表格报销总额（附表格）；两月销售对比；名单按部门统计；合同违约金每日金额（附 3000 字合同，考长文档+FactGuard） |
| 信息 | 4 | 主要观点列三条；财报营收同比（附长文本）；两方案优缺点对比；英文邮件翻译 |
| 文件 | 5 | 桌面 .docx 清单；图片按日期重命名；查张三报销单；计算 1234×5678（承 benchmark 原题）；合同转 PDF（附长文本） |

### 活儿集（5~10 题，真实性，待用户补充）

从用户手头真实待解决的活儿中征集。首轮实测一石二鸟：既是基线测量，也是真实交付。与固定集分开报告（可比性靠固定集，真实性靠活儿集）。

### 外科手术题（专测 G-16 协作记忆）

- **重复任务题 ×2**：同类活儿隔场做两次（会议纪要、表格汇总），第二次干预数应下降——不降即坐实跨会话失忆；
- **偏好题 ×1**：记忆面板手动设"输出要简洁"→ 执行周报任务，行为应变——预期不变即坐实死存储。

## 监考记录字段（每题）

可交付（是/否）、耗时、干预次数、路径（L0/L0.5/L2/RaaP/失败）、失败幕（路由/计划/执行/守卫/输出）、traceId（归因依赖 H-1 批修复 G-8）。

## 判卷（结合式）

1. **硬指标断言**（自动）：数值答案对错、文件存在性、格式合法性——逐题预置断言；
2. **模型判卷**（自动）：可交付与否，判卷 prompt 固定并版本化；
3. **抽样人工复核**：每轮抽 20% 人检，校准模型判卷误判率。

## 及格线 v1（2026-09-19 定死）

| 指标 | 线 |
|---|---|
| 可交付率 | ≥ 80% |
| 零干预率 | ≥ 60% |
| 平均耗时 | < 2 分钟 |

## 成绩单格式

```
版本 <X> vs 及格线 v1
可交付率：__%（线 80%）  零干预率：__%（线 60%）  平均耗时：__（线 2min）
固定集 / 活儿集 / 手术题分开报告
头号失败原因：<失败幕统计>
```

## 考试器实现约束

- **走真实主路径**（dialogStore 发送 / 生产 funnel），禁止 benchmark 式平行实现（benchmarkRunner.ts:110-175 的手工漏斗重放不复用）；
- 复用 benchmark 的题库结构与隔离机制：taskType 'exam' 记账隔离 + 实例级指纹缓存（P1-33 模式）；
- 前置依赖：H-1 批（G-8 traceId）先行，否则失败无法归因；
- 考试期间生产学习回路正常记账（exam 隔离标记保证不污染），行为等价真实使用。
