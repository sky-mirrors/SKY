# DeepSeek V4 Flash Token优化压测

## 概述

本压测工具对比 **Baseline（无优化）** 和 **Optimized（完整L0/L0.5/缓存/级联路由）** 两种模式下的Token消耗和成本差异。

## 前置条件

1. **DeepSeek API已配置**：在主窗口的API设置中配置DeepSeek V4 Flash模型网关
2. **API Key有效**：确保有足够的API调用额度
3. **应用已启动**：压测运行在Electron应用内

## 如何运行

1. 启动SKY应用
2. 点击标题栏的 📊 按钮打开压测台窗口
3. 设置请求间隔（建议2000ms，避免触发API限频）
4. 点击 🚀 开始压测
5. 等待两轮测试完成（约1-3分钟，取决于网络和API响应速度）
6. 查看结果表格，点击 💾 导出报告

## 测试用例分组

| 组别 | 用途 | 数量 | 预期优化路径 |
|------|------|------|-------------|
| A | 重复高频任务 | 6 | L0/指纹缓存命中 |
| B | 语义相似不同表述 | 4 | L0.5关键词匹配+nano层 |
| C | 长尾复杂任务 | 2 | RaaP完整规划 |
| D | 简单查询 | 2 | L0直通+nano层 |
| E | 合同审查类 | 2 | RaaP+FactGuard路径 |

## 定价（DeepSeek V4 Flash）

| 类型 | 价格 |
|------|------|
| Input (未缓存) | ¥1.0 / 百万tokens |
| Input (服务端缓存命中) | ¥0.02 / 百万tokens |
| Output | ¥2.0 / 百万tokens |

## 结果解读

- **tokenSavedPercent > 50%**：L0/L0.5路由高效覆盖了大部分高频操作
- **cacheHitRate > 80%**：生产级水平，缓存几乎覆盖所有重复请求
- **costSavedPercent < 30%**：复杂任务(C组)占比较高，考虑增加A组重复项以凸显缓存优势

## 输出文件

`benchmark-result.json` 保存在项目根目录，包含：
- `baseline`：基线测试原始数据
- `optimized`：优化测试原始数据
- `improvement`：节省百分比汇总
- `raw`：原始差值

## 注意事项

1. **API限频**：DeepSeek V4 Flash可能限制请求频率(如10 RPM)。如遇429错误，增大请求间隔。
2. **真实API调用**：压测会产生实际API费用，预计约 ¥0.01-0.05。
3. **首次运行**：优化模式下首次请求无缓存，后续重复请求才会命中缓存。
4. **环境一致性**：基线和优化测试使用同一API配置，确保对比公平。
